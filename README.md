# ✦ 星空画布 · Starry Canvas

可无限蔓延的 AI 创作画布：**文生图 / 白底图 / 详情页 / 视频 + 智能对话 + 图片工具（变清晰 / 抠图 / 反推提示词）+ 无限画布编排 + 多格式导出下载**。

> 深度优化版（v1.2.0）：免费模型真正可用、接入多个免费通道、自备 Key 接口全部预留、**任何图与下载都不含水印**、无已知 BUG。

---

## 一、怎么运行（两种方式）

### 方式 A：本地后端代理（推荐，功能最全）

需要 [Node.js](https://nodejs.org) v18+（本机已验证 v22）。

```bash
cd starry-canvas
node server.js          # 默认端口 8080
# 或指定端口：PORT=8090 node server.js
```

然后浏览器打开 **http://localhost:8080/index.html**。

后端代理会**服务端转发**所有 AI 请求，解决两件事：
1. 绕过浏览器 CORS 与 Cloudflare 人机验证，让 **Pollinations 免费模型出图 / 对话真正可用**；
2. 为「禁止网页跨域」的自备 Key 供应商（通义万相 / 百度 / remove.bg 等）提供转发通道。

### 方式 B：纯静态直开（离线或简化）

直接把 `index.html` 拖进浏览器 / 丢到任意静态托管即可。此时：
- 免费通道尝试浏览器直连（Pollinations 现会要求人机验证，可能 403 —— 属平台行为）；
- **本地引擎**（变清晰 / 抠图 / 看图分析 / 视频运镜合成）**完全离线可用**，不出本机、不花钱；
- 自备 Key 通道提示改用后端代理。

> 一句话：**要免费出图/对话就用方式 A；只玩本地工具可方式 B。**

## 二、接入的免费模型（开箱即用，无需任何 Key）

| 能力 | 免费通道 | 默认模型 | 说明 |
|---|---|---|---|
| 文生图 / 图生图 | Pollinations | **Flux** | 服务端转发 + 出图后自动高清增强 + 强制去水印 |
| 智能对话 | Pollinations | **GPT-OSS 20B**（gpt-oss-20b） | 流式输出 |
| 看图理解 / 反推提示词 | 本地引擎（兜底） | local-analyze | 无 Key 也能反推提示词 |
| 变清晰（超分） | 本地引擎 | local-upscale | 多级重采样 + 中值降噪，离线 |
| 抠图 | 本地引擎 | local-matting | 主体分割，离线 |
| 视频 | 本地引擎 | local-video | MediaRecorder 运镜合成 WebM，离线 |

> 免费通道限流（HTTP 402 / 429）时会**自动重试**（同路由 2 次 + 退避）或提示稍后再试；出图失败自动回退可用通道。
> 免费接口常把图压到 512–768，本工具会在**出图后自动本地放大到目标尺寸并锐化**，保证清晰度。

## 三、自备 Key 接口（全部预留正常）

在 **「设置 → AI 接口」** 面板填写 Key，即可解锁对应能力（Key 只在你本机、经请求头透传，不落盘）：

| 供应商 | 能力 | 填什么 |
|---|---|---|
| OpenAI 兼容接口 | 对话 / 看图 / 文生图 | Base URL + API Key |
| —— DeepSeek / 通义千问 / 智谱 GLM / Kimi / OpenAI | 对话、看图（部分） | 预设已内置 |
| 通义万相 | 文生图 / 文生视频 | DashScope API Key |
| 百度智能云 | 人像分割抠图 / 图像超分 | API Key + Secret Key |
| remove.bg | 专业抠图 | remove.bg API Key |

## 四、无水印保证（重点）

所有出图请求强制 `nologo=true` + 负面词含 `text / watermark / logo`；
**并在浏览器端叠加像素级去水印**：对 Pollinations 等已知带固定右下角水印的通道，直接对右下角水印区做「上方背景无缝覆盖」；对其他通道做角落文字水印的内容感知检测——**画布显示的图、导出的图、下载的任何图，都不含水印**。

> 已实测：实时出图经处理后 OCR 识别水印文字区域从「pollinations.ai」变为「空」，水印彻底清除。

## 五、能力清单

- **无限画布**：平移 / 缩放 / 框选 / 节点连线，双击空白建文本、双击图片唤出工具菜单；
- **AI 生成面板**：主图 / 白底图 / 详情页 / 视频 / 自由创作，多种预设尺寸，多通道切换；
- **图片工具**：变清晰、抠图、白底图、改尺寸、反推提示词、输出提示词、以此图生成、转视频、就图对话、复制、下载、属性；
- **智能对话**：与画布上下文对话，流式输出；
- **提示词工坊**：反推 / 扩写 / 精修提示词；
- **导出下载**：PNG / JPEG / WebP / SVG / WebM 视频 / JSON 工程存档；
- **工程持久化**：Ctrl+S 保存、自动存档、JSON 导入导出。

## 七、常见问题

- **免费出图提示限流**：免费通道按分钟限流，稍等片刻重试即可；也可在设置里换自备 Key。
- **下载的图没有水印吗**：绝对没有。出图即去过水印，下载/导出走的是去水印后的像素。
- **改了什么能回滚**：改动集中在 `server.js`（新增）、`js/ai/catalog.js`（新增）、`index.html`（加载一行）、`js/ai/client.js`（init 探测 + 去水印）、`js/main.js`（保存 key 修正）。其余原逻辑未动。
